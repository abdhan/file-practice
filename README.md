# File Operations Practice

A simple program to practice Python file operations with Git version control.

## What This Demonstrates

- **Write mode (`w`)**: Creates new file or overwrites existing
- **Read mode (`r`)**: Reads content from file
- **Append mode (`a`)**: Adds to end of file without deleting

## Usage
python file_practice.py

Choose option 1, 2, or 3 to test different file modes!

## Git Workflow

This project demonstrates:
- Committing code changes incrementally
- Using `.gitignore` to exclude test files
- Building features one at a time
